🗺 정확한 가게 위치 검색 미설정

카카오맵 JavaScript 키
입력하면 "종로의 시애틀커피하우스" 같은 검색으로 정확한 가게 위치를 찾아요. 미설정 시 OSM 기반 대략적 위치로 동작합니다.

발급 방법 (무료) — developers.kakao.com → 앱 추가 → 제품 설정 → 카카오맵 → 활성화 ON → 앱 설정 → 플랫폼 키 → JavaScript 키에서 도메인 등록 후 키 복사

🤖 이미지 자동 정보 추출 미설정

Google Gemini API 키
입력하면 캡쳐 이미지에서 상호명/지역/제공 내용/마감일을 AI가 자동 추출해요. 무료 할당량: 하루 1500회 (개인 사용에 충분).

발급 방법 (무료)
1. aistudio.google.com/apikey 접속 → Google 로그인
2. Create API key 또는 API 키 만들기 클릭
3. 생성된 키 복사 → 위에 붙여넣기
※ 별도 도메인 등록 같은 거 필요 없어요. 키 발급만 하면 됨.
