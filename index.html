체험단 매니저에 오신 걸 환영해요

체험단 일정을 AI로 자동 등록하고
마감일을 놓치지 않도록 도와드려요.

  • ✨ 캡쳐 이미지에서 AI가 정보 자동 추출
  • 📅 마감일 임박 카드는 자동 강조
  • 🗺️ 지도에서 가게 위치 한눈에
  • 📱 핸드폰 홈화면에 추가해서 앱처럼
📷

AI로 자동 등록하기

체험단 공고 캡쳐만 있으면 끝이에요.

  1. 캡쳐 — 체험단 공고 페이지를 캡쳐
  2. 업로드 — 상단 박스에 클릭·드래그·Ctrl+V
  3. 확인 — AI가 상호명·지역·내용·마감일 자동 추출
  4. 저장 — 필요시 수정 후 저장
💡 무료는 하루 3회, 프리미엄은 무제한이에요
🗂️

일정 관리

세 가지 탭으로 깔끔하게 관리해요.

  • 진행 중 — 마감 전 체험단들
  • 지도 — 가게 위치를 한눈에
  • 완료 — 리뷰 작성 끝난 것들
💡 마감일이 임박하면 카드 색이 자동으로 변해요
🗺️

지도와 위치

가게 위치를 지도에서 확인할 수 있어요.

  • 핀을 클릭하면 가게 정보가 떠요
  • 핀 색깔은 진행 중·완료·임박에 따라 달라요
💡 지도 핀이 엉뚱한 곳에?
카드를 열고 실제 주소 옆 ✏️ 버튼을 누르면 직접 수정할 수 있어요.
