🎞️GIF 스튜디오

GIF와 MP4(동영상)를 함께 올릴 수 있어요. MP4는 자동으로 GIF로 변환되고, 모든 파일을 목표 용량에 맞춰 압축해요. 파일마다 크롭·부메랑·구간(트리밍)을 적용할 수 있어요.

fps·최대 너비는 GIF·MP4 모두 적용돼요. 결과는 항상 목표 용량 이하로 맞춰져요.

🎞️
여기로 GIF·MP4를 끌어다 놓거나 클릭해서 선택 여러 파일 동시 선택 가능 · gif / mp4 / webm / mov 등
사용 팁
• MP4를 올리면 지정한 fps로 캡처해 GIF로 변환한 뒤 목표 용량에 맞춰 압축해요. GIF도 같은 fps·최대 너비가 적용돼요.
• 각 파일의 ✎ 편집에서 크롭·회전(90°)·배속(0.5~3×)을, ⌖ 구간으로 변환할 시작/끝 시간을, ↺ 부메랑으로 정·역방향 루프를 켤 수 있어요. (파일마다 따로 설정)
• 전체 변환·압축 시작으로 한꺼번에, 또는 각 카드의 개별 버튼으로 하나씩 처리할 수 있어요.
• 압축은 해상도 → 색상 → 프레임 순으로 자동 조절하며, 화질을 최대한 지키면서 목표값 바로 아래에 맞춰요.
