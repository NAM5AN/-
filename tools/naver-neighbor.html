↑ 이 버튼을 브라우저 위쪽 북마크바로 끌어다 놓으세요.

드래그가 잘 안 되나요?

드래그가 안 되면 복사해서 추가할 수 있어요. 먼저 아래 ①②를 복사해 두고, 쓰는 브라우저에 맞춰 따라 해주세요. (북마크바가 안 보이면 Ctrl+Shift+B)

① 이름 나만 추가한 이웃 찾기
② 주소
🟦 엣지(Edge)
  1. 위 ② 주소 [복사]를 눌러요.
  2. 북마크바 빈 곳에서 오른쪽 클릭 → [붙여넣기] → 북마크가 하나 생겨요.[붙여넣기]가 회색이면 ②를 먼저 복사하세요. 제목이 길고 이상하게 떠도 정상이에요.
  3. 방금 생긴 그 북마크에서 오른쪽 클릭 → [이름 바꾸기] (또는 편집).
  4. 이름을 나만 추가한 이웃 찾기로 바꾸면 끝이에요. 위 ① [복사]를 붙여넣으면 편해요.
🟢 크롬 · 웨일(Chrome · Whale)
  1. 북마크바 빈 곳에서 오른쪽 클릭 → [페이지 추가] (웨일은 "새 북마크").
  2. 작은 창의 '이름' 칸에 위 ① [복사]한 걸 붙여넣어요.
  3. 'URL' 칸에 위 ② [복사]한 걸 붙여넣어요.
  4. [저장]을 누르면 끝!

설치가 끝나면, 네이버 블로그 관리 페이지를 열고 이 북마크를 클릭하면 결과가 떠요.

  1. 위 버튼을 브라우저 북마크바로 드래그해서 등록 (북마크바가 안 보이면 Ctrl+Shift+B)
  2. 네이버 블로그 관리 페이지를 열어요 (로그인된 상태)
  3. 방금 만든 북마크를 클릭 → 화면 오른쪽 위에 결과가 떠요
결과로 보는 것
  • ⚠️ 내가 추가했는데 나를 추가하지 않은 이웃 — 정리 후보. 클릭하면 그 블로그가 열려요.
  • ➕ 나를 추가했는데 내가 추가하지 않은 이웃 — 서로이웃 맺으면 좋은 후보.
  • ⤓ CSV로 복사·다운로드 — 엑셀에서 바로 열려요.

곧 추가 예정 · 결과를 정기적으로 저장하면, 원래 서로이웃이었다가 끊긴 "뒷삭"까지 추적할 수 있어요.

읽기 전용 도구예요. 네이버 계정 정보는 전송하지 않고, 본인 로그인 세션으로 이웃 목록만 읽어 브라우저 안에서 비교해요. 자동 삭제·자동 신청 기능은 없습니다.
