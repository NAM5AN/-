02 · PHOTO LIBRARY

사진 불러오기와 목록 관리

JPG·PNG·WEBP를 한 장 또는 여러 장 불러온 뒤, 하단 목록에서 편집할 사진을 선택합니다.

  • 추가: 왼쪽 카드, 중앙 ＋, 하단 ＋ 버튼으로 사진을 더 불러옵니다.
  • 다중 선택: Shift+클릭은 구간 선택, Ctrl+클릭은 개별 추가·해제, Ctrl+A는 전체 선택입니다.
  • 이동: 하단 썸네일을 클릭하거나 ←·→ 키로 이전·다음 사진을 봅니다.
  • 우클릭 메뉴: 선택 사진 추출, 프리셋 저장, 설정 복사·붙여넣기, 사진 삭제를 실행합니다.
  • 삭제: 선택 후 Delete 키를 누르거나 우클릭 메뉴의 삭제를 선택합니다.
03 · ADJUSTMENTS

빛과 색을 섬세하게 보정하기

오른쪽 막대를 움직이면 현재 사진에 즉시 적용됩니다. 여러 사진을 선택한 뒤 자동·흑백·초기화 또는 프리셋을 적용하면 모두 함께 바뀝니다.

  • 빠른 보정: 자동은 기본 보정을 적용하고, 흑백은 색을 제거하며, 초기화는 모든 값을 원래대로 돌립니다.
  • 빛: 노출·대비·하이라이트·그림자·흰색 계열·검정 계열을 조절합니다.
  • 색상: 색온도·색조·생동감·채도로 전체 색감을 다듬습니다.
  • 효과: 명료도·안개 제거·비네팅으로 질감과 집중도를 조절합니다.
  • 기록: 상단 ↶·↷ 또는 Ctrl+Z, Ctrl+Y로 편집 단계를 되돌리고 복구합니다.
04 · PRESETS

프리셋을 적용하고 정리하기

왼쪽 프리셋을 클릭해 색감을 즉시 적용합니다. 여러 사진이 선택돼 있으면 같은 프리셋이 선택 사진 전체에 적용됩니다.

  • 숫자 단축키: 위에서부터 1~9번이며, 10번째 이후 프리셋에는 번호가 표시되지 않습니다.
  • 순서 변경: 프리셋을 위아래로 드래그하면 순서와 숫자 단축키가 함께 갱신됩니다.
  • 나만의 프리셋: 사진 우클릭 → 프리셋 저장으로 현재 빛·색상 값을 저장합니다.
  • 설정 복사: 우클릭 메뉴에서 설정값을 복사한 뒤 다른 사진 한 장 또는 여러 장에 붙여넣습니다.
  • 미리보기: 프리셋 썸네일은 현재 사진에 적용될 색감을 미리 보여줍니다.
05 · CROP & ROTATE

원하는 비율과 각도로 맞추기

상단 자르기 또는 Tab 키로 화면을 전환합니다. 프레임과 사진 위치를 조절해 원하는 구도를 만든 뒤 회전과 맞춤을 적용합니다.

  • 비율: 원본·1:1·4:5·16:9 중 선택하고 자르기 영역의 모서리를 드래그해 크기를 바꿉니다.
  • 위치: 사진 또는 자르기 영역 안쪽을 드래그해 남길 부분을 이동합니다.
  • 회전·반전: 90° 회전과 좌우·상하 반전을 버튼으로 적용합니다.
  • 미세 회전: 사진의 네 가장자리에서 드래그하며, Shift를 누르면 45° 단위로 맞춰집니다.
  • 자동 맞춤: 자동·수평·수직으로 선을 분석하거나 가이드선을 직접 긋고, 재설정으로 맞춤을 해제합니다.
06 · VIEW & EXPORT

확인하고 고화질로 저장하기

확대 상태와 원본을 확인한 뒤 저장합니다. 모든 편집은 서버 전송 없이 현재 브라우저 안에서 처리됩니다.

  • 확대·이동: 보정 화면에서 휠로 확대·축소하고, 확대된 사진을 드래그해 이동합니다.
  • 화면 맞춤: 하단 배율 버튼으로 확대와 위치를 한 번에 초기화합니다.
  • 원본 비교: 원본 비교 버튼 또는 \ 키로 편집 전·후를 빠르게 확인합니다.
  • 전체보기: 상단 ? 옆 버튼으로 편집기를 브라우저 창 크기에 맞게 넓혀 사용합니다.
  • 저장: 한 장은 JPG, 여러 장은 ZIP으로 저장되며 파일명 끝에 _01, _02 순서가 붙습니다.
✓편집한 사진을 저장했습니다.
