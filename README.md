# 체험단 매니저 (Review Manager)

> AI 기반 체험단 일정 자동 관리 SaaS

🔗 **Live**: https://cheheomdan-manager.com

## 주요 기능
- 카카오/구글 OAuth 로그인 (Supabase Auth)
- AI 기반 체험단 일정 OCR 추출 (OpenAI gpt-4o)
- 카카오맵 연동 위치 표시
- 일정 캘린더 뷰

## 기술 스택
- **Frontend**: Vanilla JS (단일 HTML)
- **Backend**: Vercel Serverless Functions
- **Database & Auth**: Supabase
- **AI**: OpenAI gpt-4o
- **Maps**: Kakao Maps SDK
